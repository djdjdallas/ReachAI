# Outreach gate

The agent only auto-replies to threads the founder initiated through the in-app outreach composer. On every inbound DM, the webhook handler at `src/app/api/webhooks/instagram/route.js` queries the conversation's earliest `messages` row before generating a reply: if `source = 'manual'` the gate passes and the agent runs, otherwise the inbound is persisted as a normal `lead` row, `conversations.last_skip_reason` is set to `'not_outreach_initiated'`, and a PostHog `agent_gate_skipped` event fires for telemetry. The composer at `POST /api/outreach/start` (UI button on the conversations page) is required because Instagram echo events for DMs sent from the IG mobile app are filtered at `route.js:67` before persistence — so without the composer there is no way for a `manual` first row to exist and the gate would lock out 100% of legit outreach. The composer resolves usernames to IGSIDs via the Meta Business Discovery API, which has a known platform limitation: it only works for **public business or creator accounts**. Personal Instagram accounts cannot be resolved by username; for those the founder must paste a raw IGSID into the same field.
